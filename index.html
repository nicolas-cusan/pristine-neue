Pristine NeueVanilla JavaScript form validation

About 3 kB gzipped, with no dependencies. It validates from the HTML attributes you already write, and supports custom, async and translated validators.

Get started
View on GitHub

Uses your HTML

required, type="email", min, max, minlength, maxlength and pattern work as they are. There's no schema to write.

Custom validators

Add a rule to one field, or register it once and use it anywhere with a data-pristine-* attribute.

Async validation

Validators can return a Promise, so you can check a username or a coupon code with your server.

Translated messages

Override any message per field or per language, with placeholders for the value and the parameters.

See it in action ​

Submit the form while it's empty, then fix the fields one by one. After the first submit, Pristine checks each field as you type.

Try it

Submit the form to check it.

html
<form>
  <div class="field">
    <label for="signup-name">Name</label>
    <input id="signup-name" name="name" type="text" required minlength="2" />
  </div>
  <div class="field">
    <label for="signup-email">Email</label>
    <input id="signup-email" name="email" type="email" required />
  </div>
  <div class="field">
    <label for="signup-password">Password</label>
    <input id="signup-password" name="password" type="password" required minlength="8" />
  </div>
  <div class="field">
    <label for="signup-confirm">Repeat the password</label>
    <input id="signup-confirm" name="confirm" type="password" required data-pristine-equals="#signup-password" data-pristine-equals-message="The passwords don't match" />
  </div>
  <div class="field">
    <label><input name="terms" type="checkbox" required data-pristine-required-message="Please accept the terms" /> I accept the terms</label>
  </div>
  <button type="submit">Create account</button>
</form>
js
const pristine = new Pristine(form);
